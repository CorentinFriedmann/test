# ESTRAN : ce qu'il y a à faire pour la porte P2

Vous ne faites rien d'autre que **jouer** et **répondre**. Comptez 15 à 20 minutes en tout.

**Lien du jeu : (en attente, la Coordination l'ajoutera ici)**

## 1. Jouer (5 à 10 minutes)

- Ouvrez le lien, cliquez sur l'écran pour commencer. **Mettez un casque si vous en avez un**, son activé.
- Le jeu n'explique rien : c'est voulu. Ne cherchez pas d'aide, jouez.
- Touches (aussi affichées à l'écran de départ) : ZQSD ou WASD pour se déplacer, souris pour regarder, Maj pour courir, C pour marcher lentement, F pour la lampe, E (maintenu) pour interagir, R pour recommencer, M pour couper le son, K pour les sous-titres des bruits, F2 pour la mesure de performance, Échap pour la pause.
- Jouez une partie complète, ou au moins 10 minutes.

## 2. Question P1 : le jeu est-il fluide ?

1. Jouez **avec le son** environ **60 secondes dans un passage bruyant** (en courant, dans l'eau).
2. Appuyez sur **F2**, puis sur **« Copier le rapport de performance »** (aussi disponible sur l'écran de départ, après Échap).
3. Collez le texte dans la conversation.

Si c'est trop compliqué : dites simplement **« fluide »** ou **« saccadé »**. C'est suffisant.

## 3. Question P2 : les 8 questions

1. Après votre partie, appuyez sur **Échap** : l'écran de départ revient. Cliquez sur **« Questionnaire (8 questions) »**.
2. Répondez avec vos mots, sans relire quoi que ce soit. Une question laissée vide reste « en attente ».
3. Pour la question 7, refaites 2 minutes en coupant le son (touche M) ; pour la question 8, essayez les sous-titres (touche K).
4. Cliquez sur **« Copier mes réponses »** et **collez le texte dans la conversation**. Si la copie est bloquée, le texte apparaît sélectionné sous les boutons : faites Ctrl+C, puis collez.

## 4. Rien d'autre à faire

Pas d'installation, pas de compte, rien à payer. Les agents traitent vos réponses.

Ce que ce test ne prouve pas : la porte P2 n'est pas franchie tant que vos réponses ne sont pas reçues et évaluées. Les mesures de fluidité faites par les agents sont en rendu logiciel, sans carte graphique ; seule votre machine dit la vérité (BUG-004).
